Información de la página

Todo lo que necesitas saber para utilizar la página.

📖

¿Cómo usar la página?

  1. Ingresa a "Solicitar Licencia".
  2. Completa tus datos personales.
  3. Selecciona las fechas.
  4. Escribe el motivo.
  5. Adjunta una imagen de respaldo.
  6. Presiona "Enviar solicitud".
✅

Recomendaciones

  • Revisa tus datos antes de enviar.
  • Verifica correctamente las fechas.
  • Utiliza imágenes claras.
  • Explica claramente el motivo.
  • Realiza la solicitud con anticipación.
⚠️

Restricciones

  • No introducir información falsa.
  • No adjuntar imágenes incorrectas.
  • No realizar solicitudes duplicadas.
  • No utilizar el sistema para otros fines.
  • La aprobación depende de la institución.
🔒

Privacidad

La información proporcionada debe utilizarse únicamente para gestionar la solicitud de licencia estudiantil.

Los usuarios deben proporcionar información verdadera y responsable.
